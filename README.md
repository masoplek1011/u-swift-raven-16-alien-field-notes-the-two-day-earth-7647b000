A tiny deterministic Node program that writes one original line — an alien tourist's review of planet Earth, about humanity's strange feud with its own lawn — to `entry.txt`.

## Run it

```sh
node main.ts
```

It writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
